# SOWP · Portafolio

Sitio estático del portafolio de SOWP (Osvaldo Cerón). Se publica tal cual: no necesita build.

- `index.html`: la página
- `assets/`: videos, imágenes y música
- `_headers`: caché de un año para `assets/` (Cloudflare Pages y Netlify)

Publicación en Cloudflare Pages: Framework preset **None**, build command vacío, output directory `/`.
